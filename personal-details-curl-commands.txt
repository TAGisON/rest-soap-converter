=============================================================
🎯 PAYSLIP ELEMENT ENDPOINTS - COMPLETE REGISTRATION & TESTING GUIDE
=============================================================

NEW ENDPOINTS: 18 (6 fields × 3 types: OPW, APW, CPW)

Fields:
1. PAN Number (pan_no)
2. Date of Birth (dob) - UTC to IST Epoch conversion
3. Rank Date (rnkdt) - UTC to IST Epoch conversion
4. Enrollment Date (p_enrldate) - UTC to IST Epoch conversion
5. Next Increment Date (irla_next_incr_date) - UTC to IST Epoch conversion
6. Last 4 Digits of Aadhar (aadhar_no) - Extracted from masked number

API Used: PAYSLIP_ELEMENT_XYZ (where XYZ = OPW, APW, CPW)
Format: http://sampoorna.cao.local/afcao/ipas/ivrs/PAYSLIP_ELEMENT_OPW/{serviceNumber}/{category}

✅ KEY FEATURES:
- Auto UTC to IST timezone conversion for date fields
- Returns dates as Epoch seconds (Unix timestamp)
- Extracts last 4 digits from masked Aadhar number
- Comprehensive error handling and logging
