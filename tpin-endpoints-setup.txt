NEW ENDPOINTS ADDED:

✅ CheckTPINAPW → Validates TPIN for APW (category=1)  
✅ CheckTPINCPW → Validates TPIN for CPW (category=2)

REQUEST FORMAT:
- serviceNumber: The service number to check
- tpin: 4-digit PIN to validate (e.g., "1234")

RESPONSE VALUES:
- 0 = TPIN matches correctly
- 1 = TPIN doesn't match or any error

TESTING SCENARIOS
=============================================================

✅ CORRECT TPIN:
- Request: serviceNumber=977735, tpin=1234
- API Response: {"items":[{"ivrs_pin":"1234"}]}
- SOAP Response: <return>0</return>

❌ WRONG TPIN:
- Request: serviceNumber=977735, tpin=9999  
- API Response: {"items":[{"ivrs_pin":"1234"}]}
- SOAP Response: <return>1</return>

❌ INVALID SERVICE NUMBER:
- Request: serviceNumber=99999, tpin=1234
- API Response: {"items":[],"count":0} OR HTTP error
- SOAP Response: <return>1</return>

❌ MISSING PARAMETERS:
- Request: Missing serviceNumber or tpin
- SOAP Response: <return>1</return>

❌ INVALID TPIN FORMAT:
- Request: tpin="abc" or tpin="12345"
- SOAP Response: <return>1</return>
